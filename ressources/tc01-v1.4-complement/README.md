# TC01 v1.4 — complément apprenant

Ce dossier complète le paquet apprenant TC01 v1.3 pendant la transition vers le standard v1.4.

## Ce qui change

La version 1.4 conserve le dossier simulé, le cours et les outils existants, mais modifie l’évaluation sur trois points:

1. le quiz mesure d’abord la décision professionnelle et la capacité à trouver la bonne source, plutôt que la mémorisation d’un numéro d’article;
2. la feuille de réponses au quiz n’est plus une preuve obligatoire;
3. un **journal de vérification** devient le sixième livrable obligatoire.

## Journal de vérification

Utiliser `Journal_verification_TC01.csv` pour enregistrer les contrôles réellement effectués. Une ligne correspond à un contrôle ou à une décision significative.

Champs attendus:

- contrôle effectué;
- source ou document consulté;
- date du contrôle;
- résultat observé;
- décision ou conséquence;
- point à escalader, le cas échéant;
- référence de preuve anonymisée.

Aucune donnée client réelle ne doit être ajoutée dans le dépôt public ou dans l’application de démonstration.

## Règle pédagogique

La logique v1.4 est: **fait → contrôle → source → décision → trace**.

Le numéro d’un article de loi peut être utile pour documenter une conclusion, mais il n’est jamais considéré comme une compétence professionnelle s’il n’est pas relié au bon contrôle opérationnel.
