# Démarrage rapide

1. Décompresser entièrement l’archive.
2. Ouvrir `LANCER_ICI.html` dans Chrome, Edge, Firefox ou Safari.
3. Régler le nom/identifiant, le rôle, la date de début et le temps hebdomadaire.
4. Commencer au mois 1. Les mois suivants restent visibles pour planification.
5. Dans TC01, télécharger le paquet apprenant, traiter les deux remises dans l’ordre et conserver les six fichiers réels dans le dossier de preuve du cabinet.
6. Exporter régulièrement la progression JSON et la joindre au dossier de formation interne. Le bouton `Importer` restaure le travail d’une sauvegarde de la même version 2.3, puis impose de reconfirmer quiz et validations.

La progression et les références de fichiers sont enregistrées dans le navigateur utilisé; les fichiers eux-mêmes ne sont pas téléversés. Un changement d’appareil ou un nettoyage du stockage local peut supprimer la trace. Le JSON constitue une sauvegarde du travail, pas un certificat: un fichier éditable ne peut pas être traité comme une preuve d’attestation fiable par une application autonome.

TC01 v1.3 est le seul module complet de cette livraison. Les 24 autres compétences restent visibles comme fiches de cadrage, mais leur évaluation et les jalons mensuels correspondants sont bloqués tant que le contenu pédagogique complet n’est pas publié.
