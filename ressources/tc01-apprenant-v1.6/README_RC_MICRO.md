# TC01 · Micro-mission RC / Zefix

Objectif pédagogique: apprendre à identifier une entité juridique dans un registre réel sans transformer l’exercice en recopie de formulaire.

Le parcours demande d’abord 5 informations qui changent réellement le travail du junior: raison sociale exacte, forme juridique, siège, statut RC et mode de signature. IDE/UID est ensuite expliqué comme identifiant utile, sans le confondre avec une preuve d’assujettissement TVA.

L’exercice utilise Nestlé S.A. uniquement pour apprendre l’outil public réel. Léman Atelier Sàrl reste un cas fictif fermé.

Les réponses de l’apprenant sont conservées uniquement dans le navigateur local via `localStorage`; aucun fichier n’est envoyé au site. La fiche Excel historique devient facultative.
